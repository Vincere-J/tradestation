VINCERE TRADINGALGO STRATEGY REFERENCE 9.0
ORB Squeeze Trend

ORB

An opening window sets the high/low range (OGX 9:35 to 9:55, RBO 9:10 to 10:00). Trade fires when price breaks out above or below the range.

SQUEEZE

Identifies tight consolidation periods where price is coiling. Enters on the directional breakout when energy releases.

TREND

Catches sustained upside moves from late morning into the afternoon when momentum turns bullish. Long only, infrequent.

9.0 SCHEDULES

All times ET. Every algo flattens at 3:30. FOMC statement days, holidays and shortened sessions are blocked by default.

PF VERSION

If an algo has a PF variant (OGX PF, RBO PF), always use it on prop accounts. B2X, URGO, G4M and MST2 have no PF version - use as-is on prop accounts.

9.0 SET FILES

No more Low / Medium / High tiers or V1-V5. Each algo has 19 set files with the same exits; they differ only by sizing (fixed $10k to $300k, split balance, full balance).

CHOP WARNING

ORB algos perform best on clean directional opens. False breakouts in choppy sessions are the algo following its rules - not a malfunction.

CONTRACT ROLLOVER

Roll contracts every 3-4 days via Tools > Database Management. Stale contracts = no trades. Restart NT to trigger the rollover prompt.
